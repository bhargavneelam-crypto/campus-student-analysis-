# 🎓 CampusPulse – Student Lifestyle & Academic Insights

CampusPulse is a student data analytics project developed using Python. It analyzes student lifestyle and academic performance data to identify patterns and understand how factors such as study hours and attendance relate to academic results.

## 📌 Project Overview

The main objective of CampusPulse is to explore student data, generate meaningful insights, and present the results through an interactive dashboard.

The project uses Exploratory Data Analysis (EDA) and data visualization techniques to understand student academic performance.

## 🎯 Objectives

- Explore the relationship between study hours and final scores.
- Understand how attendance relates to academic results.
- Identify student performance patterns.
- Present insights through an interactive dashboard.

## 📊 Dataset Information

The project uses a dataset containing **500 student records**.

Key attributes include:

- Study Hours
- Attendance
- Sleep Hours
- Assignment Score
- Previous Score
- Final Score
- Performance Category

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd CampusPulse
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python -m streamlit run app.py
```

The dashboard will open in your web browser.
